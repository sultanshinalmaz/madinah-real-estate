# Madinah Real Estate — демо Telegram Mini App

Демо-версия мини-аппа для риелтора **Абу Исхака** (Telegram @abuishak_mada,
канал [@MadinahDom](https://t.me/MadinahDom), WhatsApp +966 54 725 6674).
Панели управления пока нет — квартиры записаны в `assets/js/data.js`.

Открыть: `index.html` в браузере (или любой статический хостинг: Vercel, Netlify, GitHub Pages).
Сборка не нужна, сервер не нужен.

## Что умеет

- **Заставка** — створки двери с решёткой машрабии расходятся, ключ из эмблемы поворачивается в замке.
  Показывается при каждом запуске, начинается только когда экран реально виден, минимум 3,6 с,
  есть «Пропустить» и аварийный выход через 10 с.
- **Список квартир** — 13 актуальных объявлений из канала (посты 36–56), фото и видео без пережатия.
  Фильтры: помесячно / на год, районы, «С мебелью», «Коммуналка включена», «Для семей», «Для сестёр»,
  «До 2 500 в месяц», избранное (♥ сохраняется на телефоне).
- **Карта** (кнопка внизу «Карта ⇄ Список») — Масджид ан-Набави и цены квартир; издалека квартиры
  собираются в метку района «Аль-Арид · 7 от 2 000», нажатие приближает.
- **Страница квартиры** — галерея фото/видео, цена и комиссия, комнаты, что в квартире,
  сколько до Харама, мини-карта, ссылка на пост в канале.
- **Бронь** — имя, кто будет жить (семья / братья / сёстры), сколько человек, дата заезда, срок,
  комментарий. Кнопки открывают **личный чат риелтора в Telegram** или **WhatsApp** с готовым текстом —
  клиенту остаётся нажать «Отправить». Приложение ничего не хранит и никуда не отправляет само.

## Что заменить

| `assets/js/data.js` → `districts` | центры районов на карте |
| `media/` | фото, видео и обложки (обложка видео — кадр из самого ролика) |
| `assets/logo.jpg` | эмблема (взята с аватарки Telegram, 320×320 — лучше прислать оригинал) |

## Мотивы оформления

| Элемент | Что это |
|---|---|
| Кремовый фон, изумруд, золото | цвета эмблемы Madinah Real Estate |
| Стрельчатая арка у всех фото | арки галерей Масджид ан-Набави |
| Решётка с «бусинами» (заставка, блок «Как забронировать») | машрабия / руушан — деревянные решётчатые окна старых домов Медины |
| Ключ | из эмблемы: «ключи от дома» |
| Купол с минаретом (шапка, метка на карте) | Зелёный купол и минарет, как в эмблеме |

Шрифты Cormorant Garamond и Manrope лежат локально (`assets/fonts`), Leaflet — в `assets/vendor`.
Карта: Esri World Street Map, запасная — OpenStreetMap.

## Проверка

`node tools/check.mjs` — открывает приложение в headless Chrome (390×844), снимает заставку,
список, страницу квартиры, бронь, видео и карту в `tools/shots/`, нажимает элементы честным касанием
и печатает ошибки консоли. Нужен Chrome или Edge и Node 22+.
